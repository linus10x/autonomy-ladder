Commercial real estate

cre-agent-audit

The README describes nine MIT-licensed governance patterns for AI agents in commercial real estate operations: tenant screening, lease abstraction, and pricing, with a hash-chained audit trail.

Scope

What the README says

  • Patterns named in the opening: a DEFCON state machine, a non-overridable sovereign veto, a hash-chained audit ledger, a Fair-Housing Pre-Flight Gate, and the A0 to A4 ladder.
  • The README states 348 tests, 88% coverage, release v0.3.0, Python 3.10 or newer, and zero runtime dependencies.
  • A cold start in the README is python examples/worked_example_fair_housing_preflight.py after pip install -e ., or ./demo.sh with no install.
  • It says this is not legal, regulatory, audit, or fairness-testing advice, and not a deployed production control.
