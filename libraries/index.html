Libraries

The six libraries, and the tools that run.

Six open governance libraries for autonomous AI in regulated operations, plus four runnable tools. This page is the family index. The GitHub index is linus10x/autonomy-ladder-libraries.

Libraries

Six DOI-archived libraries

The family README at linus10x/autonomy-ladder-libraries calls these reference implementations, not deployed production controls. Each library is MIT or dual MIT OR Apache-2.0. The license on the library page is the one that repository states.

Financial services

finserv-agent-audit

The README describes audit-trail, kill-switch, and model-risk governance for autonomous AI agents in regulated financial services, with zero runtime dependencies.

DOI 10.5281/zenodo.20434570

Library page · GitHub

Banking

banking-agent-audit

The README describes governance patterns for autonomous AI agents in regulated banking: model-risk effective-challenge, ECOA / Reg B adverse-action controls, and a sanctions workflow that ships no list.

DOI 10.5281/zenodo.20564584

Library page · GitHub

Payments

payments-agent-audit

The README describes a governance library for autonomous AI agents in regulated payments, where rail finality, OFAC strict liability, and Reg E meet deployment authority.

DOI 10.5281/zenodo.20592773

Library page · GitHub

Healthcare payer

payer-agent-audit

The README describes the audit record for a utilization-management, prior-auth, or claims/appeals decision when an AI agent touches it. It says the library makes no medical-necessity call.

DOI 10.5281/zenodo.20564377

Library page · GitHub

Private capital

private-capital-agent-audit

The README describes an Advisers Act section 206 control layer that makes an AI agent's orders, marketing, and valuation marks auditable.

DOI 10.5281/zenodo.20564496

Library page · GitHub

Commercial real estate

cre-agent-audit

The README describes nine MIT-licensed governance patterns for AI agents in commercial real estate operations: tenant screening, lease abstraction, and pricing, with a hash-chained audit trail.

DOI 10.5281/zenodo.20437081

Library page · GitHub

Tools

Four runnable tools

These four repositories are tools you can run. They are not part of the six-library DOI set. No DOI is stated in their READMEs. Each is MIT, or MIT for its own wrapper when it vendors another MIT repository.

Runnable tool

agent-funds-gate

The README describes a fail-closed control: a value-moving agent action is denied unless a version-pinned OFAC SDN screen completed before the transfer executed.

Tool page · GitHub

Runnable tool

agent-eval-gate

The README describes an MCP server over stdio. An MCP client calls authorize_funds_transfer and gets a structured verdict from a version-pinned OFAC screen-before-transfer control.

Tool page · GitHub

Runnable tool

agent-audit-packet

The README describes a forwardable OFAC audit packet. One command shows an under-governed payments agent failing a screen-before-transfer control and a governed agent passing it.

Tool page · GitHub

Runnable tool

agent-evidence-ledger

The README describes an append-only, tamper-evident ledger of decisions an autonomous agent made. verify() names which of five forgery classes was detected, and at which index.
