Libraries

Every library is reference code to adopt and inspect. None is a deployed production control. Not legal advice, not a certification or audit opinion, and no guarantee of regulatory compliance.

Financial services: finserv-agent-audit

What it does: A risk-state machine, a veto the agent can't override, a tamper-detecting audit chain and an A0 to A4 autonomy gate, plus FSI controls mapped to primary sources. It sits on top of the agent runtime you already use.

Who it's for: An FSI model-risk or compliance lead who has to produce a per-decision trail on demand.

Next step: Clone it and run ./demo.sh. It grants an agent A3, revokes it to A1 with the reason recorded, then shows four attacks being caught. No install, no network.

Banking: banking-agent-audit

What it does: Tested ECOA / Reg B adverse-action and model-risk effective-challenge controls, plus a sanctions workflow that ships no list.

Who it's for: A bank's model-risk, fair-lending or compliance lead standing up agentic decisioning.

Next step: Read and run tests/test_adverse_action_gate.py.

Payments: payments-agent-audit

What it does: Treats rail finality as an input. If an agent can move money on an instant rail, a control that fires after authorization is too late, so the gate checks first. Includes an OFAC screen with a human disposition step.

Who it's for: A payments or fintech compliance or risk lead deciding how far to trust an agent on FedNow, RTP, ACH or card rails.

Next step: Run python examples/instant_rail_promotion_refusal.py.

Healthcare payer: payer-agent-audit

What it does: Records whether a clinician was present and attested, whether a UM, prior-auth or claims decision was timely under the rule for that plan's funding type, and whether appeal rights were given. It makes no medical-necessity call.

Who it's for: A health plan's compliance, model-risk or engineering lead putting agents into UM, prior-auth or claims work.

Next step: Clone the repo and start with the funding-type obligation routing example listed in the library hub.

Private capital: private-capital-agent-audit

What it does: An Advisers Act §206 control layer that makes an agent's orders, marketing and valuation marks auditable, with every flag written to a tamper-evident ledger.

Who it's for: An RIA or allocator compliance lead, or a buy-side AI lead.

Next step: Install it and run private-capital-audit obligations buy_side_quant.

Commercial real estate: cre-agent-audit

What it does: Governance patterns for tenant screening, lease abstraction and pricing, including a Fair-Housing Pre-Flight Gate that vetoes a screening decision that reaches for a housing-voucher feature.

Who it's for: A CRE owner or operator, or a proptech screening or compliance lead.

Next step: Run python examples/worked_example_fair_housing_preflight.py.

Tool: agent-funds-gate

What it does: Denies a value-moving agent action unless a version-pinned OFAC SDN screen completed before the transfer executed. A naive check that only asks whether a screen ran lets a $250,000 transfer through in the demo; this gate denies it. You wire in your own SDN list.

Who it's for: Anyone letting an agent move money.

Next step: Run python demo/demo.py.

Tool: agent-eval-gate

What it does: Exposes the funds gate as one MCP tool, authorize_funds_transfer, with a deadline that can't be extended past 90 seconds and any error turned into a deny.

Who it's for: An AI engineer wiring an agent through MCP.

Next step: Run ./demo.sh, then ./serve.sh.

Tool: agent-audit-packet

What it does: One command shows an under-governed payments agent failing the OFAC ordering control and the governed one passing, then writes a forwardable evidence.json with a CI exit code.

Who it's for: A reviewer or engineer who needs evidence they can forward.

Next step: Run ./verify.sh.

Tool: agent-evidence-ledger

What it does: An append-only, tamper-evident ledger of agent decisions. Verification names which of five forgery types happened (edit, delete, reorder, bypass, truncation) and where.

Who it's for: Engineers who need a decision record an auditor can check.

Next step: Run ./demo.sh.

Bank CRO

Job to be done: Show that an agent touching credit decisions gives a correct adverse-action notice and that model risk gets real effective challenge.

Fit: banking-agent-audit

Next step: Run the free self-score, then tests/test_adverse_action_gate.py.

Why now: The library maps to the 2026 revised interagency model risk guidance (OCC Bulletin 2026-13).

Payments compliance lead

Job to be done: Make sure an agent can't send money before the sanctions screen finishes.

Fit: agent-funds-gate, payments-agent-audit

Next step: Run the funds gate demo (python demo/demo.py).

Why now: On an instant rail the money is gone once it moves, and OFAC liability is strict.

Payer UM lead

Job to be done: Keep a record that a clinician attested, the decision met its deadline, and appeal rights were given, without the tool making the medical call.

Fit: payer-agent-audit

Next step: Run the free self-score, then clone the library.

Why now: The same denial can fall under CMS-0057-F, ERISA or a state clock depending on who funds the plan, and the library routes it.

RIA CCO

Job to be done: Make an agent's orders, marketing and marks auditable under Advisers Act §206.

Fit: private-capital-agent-audit

Next step: private-capital-audit obligations buy_side_quant

Why now: If an agent is already placing orders or sending marketing, each of those is a fiduciary act that needs a record.

CRE operator

Job to be done: Stop a tenant-screening agent from using a feature fair-housing rules forbid.

Fit: cre-agent-audit

Next step: Run the Fair-Housing Pre-Flight example.

Why now: The vetoed pattern is the one named in the Louis v. SafeRent settlement.

AI engineer at a fintech

Job to be done: Put a gate and a tamper-evident record in front of an agent's money moves without adding dependencies.

Fit: agent-eval-gate, agent-evidence-ledger, agent-audit-packet

Next step: Run ./verify.sh in agent-audit-packet and forward the evidence.json to your compliance team.

Why now: It exits non-zero if the control doesn't hold, so it can go straight into CI.
