agent-eval-gate

The README describes an MCP server over stdio. An MCP client calls authorize_funds_transfer and gets a structured verdict from a version-pinned OFAC screen-before-transfer control.

Scope

What the README says

  • It wraps agent-funds-gate, vendored under vendor/. The README says it is not a new control.
  • Run path: ./serve.sh to serve, ./demo.sh for the acceptance demo. No install and no network.
  • The README says a caller cannot request a deadline above 90 seconds, and an exception inside evaluation becomes a DENY.
  • License: MIT for the wrapper. The vendored control stays under its upstream MIT license.
