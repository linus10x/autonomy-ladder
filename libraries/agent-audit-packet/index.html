agent-audit-packet

The README describes a forwardable OFAC audit packet. One command shows an under-governed payments agent failing a screen-before-transfer control and a governed agent passing it.

Scope

What the README says

  • Run path: ./verify.sh. No install and no network. It wraps agent-funds-gate under vendor/.
  • The README says v1 ships one probe, the OFAC screen-before-transfer race, and writes evidence.json.
  • Exit 0 means every probe passed and the embedded suite was green. Any other code means the control does not hold, per the README table.
  • License: MIT for the wrapper. The vendored control stays under its upstream MIT license.
