Private capital

private-capital-agent-audit

The README describes an Advisers Act section 206 control layer that makes an AI agent's orders, marketing, and valuation marks auditable.

Scope

What the README says

  • The README names five primitives and seven adviser controls: best execution, MNPI surveillance, custody, marketing, allocation fairness, books-and-records, and valuation governance.
  • The README states 181 tests and 98.7% coverage. Python 3.12 or newer. Zero runtime dependencies.
  • Scope line in the README: investment advisers, under the adviser fiduciary regime.
  • It says this is reference IP, not a deployed compliance system, and not legal advice.
