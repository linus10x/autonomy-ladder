Payments

payments-agent-audit

The README describes a governance library for autonomous AI agents in regulated payments, where rail finality, OFAC strict liability, and Reg E meet deployment authority.

Scope

What the README says

  • Decision classes named in the README: the rail-finality / irreversibility gate (AL-PROBE-06) and OFAC screen to human disposition.
  • Rules named there: OFAC sanctions, Regulation E (12 CFR 1005.11), BSA/AML SAR timeliness and the Travel Rule, and rail finality.
  • The README states 183 tests and 98.97% coverage. Python 3.12 and 3.13. MIT. Zero runtime dependencies.
  • It says this is not a deployed production control, ships no SDN data, and is not legal advice.
