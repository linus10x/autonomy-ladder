agent-funds-gate

The README describes a fail-closed control: a value-moving agent action is denied unless a version-pinned OFAC SDN screen completed before the transfer executed.

Scope

What the README says

  • The README's example is a $250,000 transfer at sequence 10 whose screen does not complete until sequence 15. A naive check allows it. This gate denies it.
  • The rule cite in that denial example is 31 CFR 501.603/501.604.
  • The README states 17 tests. Run path: pytest and python demo/demo.py. No SDN list is bundled.
