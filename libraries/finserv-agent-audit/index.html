Financial services

finserv-agent-audit

The README describes audit-trail, kill-switch, and model-risk governance for autonomous AI agents in regulated financial services, with zero runtime dependencies.

Scope

What the README says

  • Composable Python primitives: a risk-state machine, a non-overridable sovereign veto, a tamper-detecting audit chain, and an A0 to A4 autonomy gate, plus financial-services controls.
  • The README states 722 tests, 94% coverage, and current version v2.3.0. Python 3.12 or newer. Zero runtime dependencies.
  • It says this is not a model, an agent framework, or legal advice, and that it does not make decisions.
  • Start with ./demo.sh after a clone. The README says that script needs no pip install and no network.
