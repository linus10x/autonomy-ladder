agent-evidence-ledger

The README describes an append-only, tamper-evident ledger of decisions an autonomous agent made. verify() names which of five forgery classes was detected, and at which index.

Scope

What the README says

  • Forgery classes named in the README: edit, delete, reorder, bypass, and truncation.
  • The same chain can hold a sovereign-veto record and an auto-demote record. The README says demotion is recorded from an external drift signal. The primitive does not detect drift.
  • Run path: ./demo.sh. Tests: ./run_tests.sh. No network.
  • The README maps the ledger to SEC Rule 17a-4(f)(2)(i)(A), 17 CFR 240.17a-4(f)(2)(i)(A). License: MIT.
