Banking

banking-agent-audit

The README describes governance patterns for autonomous AI agents in regulated banking: model-risk effective-challenge, ECOA / Reg B adverse-action controls, and a sanctions workflow that ships no list.

Scope

What the README says

  • Decision classes named in the README: ECOA / Reg B section 1002.9 adverse-action notice, model-risk effective-challenge, and a sanctions disposition workflow.
  • The README states 182 tests and about 99% coverage. Python 3.12 or newer. Zero runtime dependencies.
  • It says the OFAC workflow is a reference pattern only and ships no sanctions list.
  • It says this is reference IP, not a control deployed inside a bank, and not legal advice.
