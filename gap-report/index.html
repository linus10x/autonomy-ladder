Written for this page to show the format. It is generic and is not taken from any firm's report.

Example control: stopping an agent. Example answer: an agent can only be stopped by changing and redeploying its code. A stronger answer: a named person can pause the agent within minutes, and each pause is logged with who did it and why.

Example questions a reviewer might raise:

  • Who has the authority to pause this agent today, and how would they reach it on a weekend?
  • When was a pause last tested, and where is the record of that test?
  • What happens to work the agent had started when it is paused?
