Hosting

Static site on Cloudflare

The site is static files served on Cloudflare. The repo config publishes the repository as assets and does not name an application server. The diagnostic self-score runs in the browser. The product page states that nothing you type is sent until you choose to email yourself the brief, and that there is no account and no card on this site.
